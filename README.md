# Candy Crush Clone (Flutter)

Flutter + [Flame](https://flame-engine.org/) port of the KorGE match‑3 sample **[TobseF/Candy-Crush-Clone](https://github.com/TobseF/Candy-Crush-Clone)**. Gameplay and assets follow the upstream project; this repo contains the Dart/Flutter implementation.

## Getting started

```bash
flutter pub get
flutter run
```

Release APK:

```bash
flutter build apk --release
```

Output: `build/app/outputs/flutter-apk/app-release.apk`.
